# BathCentric: image prompts, ready to copy

Work through this file **from top to bottom**. Every prompt below is complete (style + subject + negative):
copy the whole block into your image tool, set the **shape** shown, generate, and save with the **exact file name**
into the `photos/` folder. Then run `npm run dev` to see it on the site.

Tips
- Set the shape in your tool (Midjourney: add `--ar 16:9` etc. · ChatGPT / Gemini / Firefly: choose the size).
- If your tool has a separate "negative prompt" box, paste the line starting with **Avoid:** there.
- Use a tool or plan that does **not** add a watermark or ✦ mark.
- Keep the best result of each, and don't worry about file size: the site compresses it.
