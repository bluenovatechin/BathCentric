# BathCentric: new image prompts, ready to copy

Prompts for the images on the **Services, Mirrors, Linear Drains, Accessories** pages, written in the same
style as the rest of the site, so every photo looks like it belongs to the same set.

Work through this file **from top to bottom**. Every prompt is complete (style + subject + things to avoid):
copy the whole block into your image tool, set the **shape**, generate, and save with the **exact file name**
into the `photos/` folder (replace the old file with the same name). Then run `npm run dev` to check it.

## How to use these prompts
- **Shape for every image in this file: 3:2 landscape, at least 2400 × 1600.**
  (Midjourney: add `--ar 3:2` · ChatGPT / Gemini / Firefly: choose a wide landscape size.)
- If your tool has a separate "negative prompt" box, paste the line starting with **Avoid:** there.
- `.jpg`, `.png` or `.webp` all work. Don't resize or compress; the site does it.
- **Right edge:** the site trims a thin strip from the right edge of landscape images (that's where generator
  marks like ✦ appear). Keep anything important away from the far right.
- **Faces:** none. Show people from behind, or only their hands.

## The BathCentric look (already built into every prompt)
| | |
|---|---|
| Mood | Quiet luxury: bright, airy, calm and architectural, like a high-end interiors magazine |
| Light | Soft natural daylight from a window, gentle shadows, never harsh or HDR |
| Palette | Warm white walls, large-format light stone tiles, pale oak, brushed metal; one deep navy accent at most (a folded towel) |
| Glass | Frameless 8mm toughened glass, crystal clear with a faint blue edge |
| Metal | One finish per picture: Chrome, Rose Gold, Matte Black or Gold, the catalogue finishes |
